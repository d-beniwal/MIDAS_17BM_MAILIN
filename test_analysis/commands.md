# Test analysis — commands run

Smoke test of `calibrate.py` / `integrate.py` after: turning off residual-map
correction (`build_residual_corr=False`), switching `refine_distortion` to
`'radial'`-only, and adding `integrate.py --plot`. Single calibration frame
used for both calibration and integration. Run from the repo root
(`/Users/dbeniwal/ANL-research/MIDAS_17BM_MAILIN`), with all outputs written into
this `test_analysis/` folder, using the `test_data/` copy of the frame (not
`beamline_data/`, which is gitignored) so this test is fully reproducible
from what's checked into git. Run inside the `midas_17bm` conda environment
(see `environment.yml`):

```bash
conda activate midas_17bm
```

## 1. Calibrate

```bash
python calibrate.py \
  --infile test_data/Lab6_d1000_20260212_49keV-00000.tif \
  --outfolder test_analysis \
  --overwrite
```

Produces:
- `Lab6_d1000_20260212_49keV-00000_midas_calib.json` — calibration geometry
  (Lsd=1001.310 mm, BC=(1458.337, 1428.090) px, distortion refined to
  `iso_R2/iso_R4/iso_R6` only — all azimuthal (a*/phi*) terms fixed at 0, per
  `refine_distortion='radial'`; `residual_corr_bin: null` since
  `build_residual_corr=False` means no `.bin` is produced).
- `Lab6_d1000_20260212_49keV-00000_midas_calib.png` — ring-overlay image
  (always generated by `calibrate.py`).

## 2. Integrate (same frame, against its own calibration), with the lineout plot enabled

```bash
python integrate.py \
  --incalibfile test_analysis/Lab6_d1000_20260212_49keV-00000_midas_calib.json \
  --infile test_data/Lab6_d1000_20260212_49keV-00000.tif \
  --outfolder test_analysis \
  --plot 1
```

Produces one file per format in `pipeline_config.INTEGRATION_OUTPUT_FORMATS`
(`.csv`, `.xye`, `.fxye`, `.dat`, `.esg`, `.2d.csv`) plus, because of
`--plot 1`:
- `Lab6_d1000_20260212_49keV-00000_lineout.png` — I vs 2theta lineout with
  +/-1 sigma band. Sharp, well-resolved LaB6 powder peaks out to ~17 deg
  2theta, confirming the calibration geometry is sound.

## Result

Both the ring-overlay PNG and the lineout PNG look correct; radial-only
distortion and disabled residual-map correction both took effect as
configured (verified directly against the written JSON's `distortion` and
`residual_corr_bin` fields). Re-run from `test_data/` inside a freshly built
`midas_17bm` environment reproduced the same geometry (Lsd=1001.3102 mm,
BC=(1458.337, 1428.090) px, post-residual strain 34.0 μϵ) and byte-identical
integration output sizes as the original `beamline_data/`-sourced run.

Note: `midas_calibrate_v2`'s auto-seeder (`midas_calibrate_v2.seed.auto_seed`)
imports `skimage` at call time but does not declare `scikit-image` as a pip
dependency — install it explicitly (see `environment.yml`) or `calibrate.py`
fails with `ModuleNotFoundError: No module named 'skimage'`.
